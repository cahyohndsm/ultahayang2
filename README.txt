# Web Ulang Tahun Romantis (Nailog Theme) ✨🎂

Web ulang tahun interaktif dengan tema aesthetic Nailog (soft pink, cute, & romantic).

## 📁 Struktur Folder File:
- `index.html` : File utama website.
- `lagu.mp3` : File lagu latar (Lagu Denny Caknan - Tunggal Eka / Sekti).
- `images/` : Folder tempat menyimpan foto-foto kenangan kamu.
  - `foto1.jpg`
  - `foto2.jpg`
  - `foto3.jpg`
  - `foto4.jpg`

## 🎵 Cara Memasang Lagu "Tunggal Eka" (Denny Caknan):
1. Unduh/siapkan lagu Denny Caknan - Tunggal Eka dalam format `.mp3`.
2. Ubah nama file lagu tersebut menjadi **`lagu.mp3`**.
3. Taruh file **`lagu.mp3`** tepat di folder utama (sejajar dengan file `index.html`).

## 📸 Cara Menambahkan / Mengganti Foto Sendiri:
1. Siapkan 4 foto favorit kamu bersama pasangan.
2. Ubah nama file foto tersebut menjadi `foto1.jpg`, `foto2.jpg`, `foto3.jpg`, dan `foto4.jpg`.
3. Masukkan 4 foto tersebut ke dalam folder **`images`**.
4. Buka file `index.html` di browser (double click), dan web siap dinikmati!
